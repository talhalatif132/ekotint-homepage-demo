# Ekotint Paints homepage demo

A responsive Next.js App Router / React / TypeScript homepage concept. The project exports to `out/` for a portable preview.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3023.

## Check and build

```sh
npm run typecheck
npm run build
```

The demo includes colour-family filtering, saved palette favourites, a prepared-scene colour preview, product information dialogs, search and a project brief saved on the current device. Payments, accounts, AI processing and actual enquiry delivery are outside this homepage demo.

Ekotint logo and product pack photography are sourced from its public website. Room imagery and font sources are recorded in `public/images/ASSET-SOURCES.md`. Displayed room palette names are illustrative design concepts rather than approved Ekotint shade codes. Product information is limited to details verified on Ekotint's public pages.
