# Ekotint Paints homepage demo

A responsive Next.js App Router / React / TypeScript homepage concept. The project exports to `out/` for a portable preview.

## Run

```sh
npm install
npm run dev
```

Open http://127.0.0.1:3023.

## Check and build

```sh
npm run typecheck
npm run build
```

The demo includes a four-scene colour-story carousel, desktop colour navigation, product filtering and detail dialogs, colour-family browsing, a prepared-scene wall preview, custom colour-picker/HEX input, saved palette favourites, search and a downloadable project brief. Favourites support both named and custom colours and migrate the earlier saved-name format. Payments, accounts, automated wall detection and actual enquiry delivery are outside this homepage demo.

Ekotint logo and product pack photography are sourced from its public website. Room imagery is original AI-generated inspiration, not a record of completed Ekotint installations. Sources and prompts are recorded in `public/images/ASSET-SOURCES.md`, `ASSET-PREMIUM-INTERIORS.md` and `ASSET-PREMIUM-EXTERIOR.md`. Displayed room palette names are illustrative design concepts rather than approved Ekotint shade codes. Product information is limited to details verified on Ekotint's public pages.
